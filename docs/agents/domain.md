# Domain docs

This repo uses a **single-context** layout for domain documentation.

- `CONTEXT.md` at the repo root (create when a high-level product overview is needed).
- `docs/adr/` contains architecture decision records.
- `docs/glossary.md` contains the project vocabulary.

When working on a ticket, read the relevant ADRs and the glossary first so ticket descriptions and code use the agreed domain language.
